# Changelog

## 1.0.0 (2026-11-21)

First public release.

- Blocks porn and gambling on-device through bundled word lists, host lists and app lists.
- Four tabs: Home, Custom, Protection and Log.
- Full-screen block cards with a two-second inert window, a touch-consuming scrim, and Close or
  Appeal actions. Appeal is offered only on soft word-match cards.
- Optional protection lock and change lock, both off by default; device admin adds only the Android
  deactivation step before uninstall.
- Custom block and exclude lists for words, sites and apps, with four optional search add-ons
  (Instagram, X, Reddit, Telegram) that are off by default and behind the lock.
- AMOLED-first UI with Dark and Light themes, eight backgrounds (Grid, Dots, Samurai, Warrior, Miku,
  Flower, Spiderweb, Sword) and tintable art colour.
- No manifest permissions, no INTERNET access, no VPN or DNS proxy, no analytics and no runtime
  dependencies.
